# 仕様書 08: View(表示)

- 実装ファイル:`dobutsu/view.py`
- テストファイル:`tests/test_view.py`

## 1. 役割
画面への **出力だけ** を担当する(盤面、持ち駒、手番、メッセージ、結果の表示)。
入力は受け付けない(`Controller` の仕事)。ルールの判定もしない。

最初はコンソール(`print`)出力で作る。将来、GUI 版に差し替えることを想定して、`Game` と `Controller` は `View` の3つのメソッドだけを呼ぶ決まりになっている。このインターフェースは変えない。

## 2. 前提知識

### 盤面の座標
- 盤面は 4行×3列。`Position(row, col)`、`row` が 0〜3、`col` が 0〜2。左上が `(0, 0)`。
- **表示は row 0 を上、row 3 を下** とする(先手が下側から上へ進む向きで表示する)。

### 駒の表示
- 駒の表示文字は `piece.symbol`(獅・象・麒・雛・鶏)。
- 先手の駒と後手の駒は見分けられるようにする。判定は `piece.owner.direction`(`-1` が先手、`+1` が後手)で行う。名前(`name`)では判定しない。
- 本仕様の表示例では先手に `▲`、後手に `▽` を付ける(将棋の棋譜の記法)。

### 持ち駒
- 持ち駒は `player.hand`(`Piece` のリスト)。種類ごとの枚数を数えて表示する(例:`雛×2 象×1`)。
- 持ち駒がなければ `なし` と表示する。

## 3. 依存するもの

| 依存先 | 使うもの |
|---|---|
| `Board` | `get(Position(row, col))` |
| `Player` | `name`, `direction`, `hand` |
| `Piece` | `symbol`, `owner` |
| `Position` | `Position(row, col)`、`BOARD_ROWS`, `BOARD_COLS` |

`View` は `Game` を import しない(循環依存を避ける)。

## 4. 属性
なし。`View()` で生成できる。

## 5. メソッド仕様

### `show_board(self, board: Board, players: list[Player], current: Player) -> None`
- **引数:**
  - `board`:表示する盤面(変更しない)
  - `players`:`[先手, 後手]` の順のリスト(2人)
  - `current`:現在の手番のプレイヤー
- **戻り値:** なし。標準出力に表示する。
- **表示内容(上から順):**
  1. 後手の持ち駒の行(盤の上側に置く)
  2. 列番号の見出し行
  3. 盤面4行(各行頭に行番号)
  4. 先手の持ち駒の行(盤の下側に置く)
  5. 手番の行
- **内部処理:**
  1. `players` から先手(`direction == -1`)と後手(`direction == +1`)を特定する
  2. 各マスについて `board.get(Position(row, col))` を取得し、セル文字列を作る
     - 駒がある:先手なら `"▲" + symbol`、後手なら `"▽" + symbol`
     - 空:`" ・"` など、幅がそろう記号
  3. 持ち駒を `symbol` ごとに数えて文字列にする(種類の並びは `hand` で最初に現れた順でよい)
  4. 上記の順に `print` する
- **表示例(初期配置、先手番):**

```
後手 持ち駒: なし
     0   1   2
 0  ▽象 ▽獅 ▽麒
 1   ・ ▽雛  ・
 2   ・ ▲雛  ・
 3  ▲麒 ▲獅 ▲象
先手 持ち駒: なし
手番: 先手
```

- **表示例(持ち駒あり):**

```
後手 持ち駒: なし
     0   1   2
 0  ▽象 ▽獅 ▽麒
 1   ・  ・  ・
 2   ・ ▲雛  ・
 3  ▲麒 ▲獅 ▲象
先手 持ち駒: 雛×1
手番: 後手
```

- 文字のそろい方は端末のフォントに依存してよい。必須条件は、**行・列の対応が分かること、先手と後手の区別がつくこと、持ち駒の種類と枚数が分かること** の3点。
- 盤面と持ち駒を変更しない。

### `show_message(self, text: str) -> None`
- **引数:** `text`:表示する文字列
- **戻り値:** なし
- **内部処理:** `text` を1行で表示する(`print(text)`)。
- **用途:** `HumanController` の入力エラーの通知、操作案内など。

### `show_result(self, winner: Optional[Player]) -> None`
- **引数:** `winner`:勝者の `Player`。引き分けなら `None`。
- **戻り値:** なし
- **内部処理:**
  1. `winner` があれば `"{winner.name}の勝ちです"` のような勝者の表示をする
  2. `None` なら `"引き分けです"` と表示する

## 6. 使われ方

| 呼び出し元 | 使うメソッド | タイミング |
|---|---|---|
| `Game.play_turn` | `show_board` | 各手番の最初 |
| `Game.run` | `show_board`, `show_result` | 終了時 |
| `HumanController` | `show_message` | 入力エラー時 |

```python
view = View()
view.show_board(game.board, game.players, game.current_player)
view.show_message("入力が不正です")
view.show_result(game.first)
```

## 7. テスト項目
標準出力の内容を調べるテストを書く。`unittest.mock.patch("sys.stdout", new_callable=io.StringIO)` や `contextlib.redirect_stdout` を使う。
**出力の文字列全体の完全一致は避け、含まれるべき文字列を確認する** (表示の細部を変えてもテストが壊れにくくするため)。

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | 初期配置を `show_board` | 出力に「獅」が2回、「象」が2回、「麒」が2回、「雛」が2回含まれる |
| 2 | 初期配置を `show_board` | 出力に `▲` が4個、`▽` が4個含まれる |
| 3 | 初期配置、`current` が先手 | 出力に `先手` を含む手番の行がある |
| 4 | 初期配置、`current` が後手 | 手番の行に `後手` が含まれる |
| 5 | 持ち駒なし | 出力に `なし` が2回含まれる |
| 6 | 先手の持ち駒にヒヨコ2枚 | 出力に `雛×2` が含まれる |
| 7 | 先手の持ち駒にヒヨコとゾウ | 出力に `雛×1` と `象×1` が含まれる |
| 8 | 後手の持ち駒だけがある | 後手の行に枚数が出て、先手の行は `なし` |
| 9 | ニワトリが盤上にある盤面 | 出力に「鶏」が含まれる |
| 10 | 行番号 0〜3、列番号 0〜2 | 出力に含まれる |
| 11 | `show_board` の前後で `board` と `hand` | 変化しない |
| 12 | `show_message("テスト")` | 出力に `テスト` が含まれる |
| 13 | `show_result(first)` | 出力に `先手` が含まれる |
| 14 | `show_result(None)` | 出力に `引き分け` が含まれる |

目視確認:テストとは別に、`main` 相当の小さなスクリプトで実際に初期盤面を表示し、見やすさを確認する。

## 8. 実装上の注意
- `View` は **状態を持たない**。表示のたびに引数から作る。
- `View` 内で `input` を使わない。
- 先手・後手の判定は `direction` で行い、`name` の文字列比較をしない。
- 後手の駒の表示は、盤面を回転させて先手側から見た向きにそろえる必要はない。**駒の向きは `▲` / `▽` で表す**。
- GUI 版に差し替える場合も、3つのメソッドの名前・引数・戻り値を変えないこと。
